# Plant Shopping Demo App
A fictional online shop website for purchasing house plants. Developed as a project for the Coursera learning program. Contains only 3 pages: Landing, Product Listing, and Cart.

## Landing Page
Main page describing the online plant shop, welcoming the user, and directs user to the product listing page via "Get Started" button.

## Product Listing Page
Picture-charted listing of plants available to purchase. Products divided into categories each consisting of six plant items. Each product card describes a certain plant along with its unit cost, image, and button to add it to the user's cart.

## Cart Page
User's personal online cart holding plant items to purchase. Cart holds as many items as the user wants to purchase, displaying subtotal cost of each item type and total cost of entire cart. User can increment and decrement quantity of each product type in cart and lets user return to product listing page to continue shopping. Cart checkout button as of now does not have functionality and displays a simple message saying its non-functional.
